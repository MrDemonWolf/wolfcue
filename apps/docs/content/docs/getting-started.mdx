---
title: Get started
description: Paste or import a script, set your pace, and read.
---

1. Open WolfCue inside the browser where you will read. Safari and Moblin keep
   separate storage, so paste or import inside Moblin itself, or open a script
   link there.
2. Paste into **Script**, or use **Import** to choose a UTF-8 `.txt` file.
3. Choose **Words per minute** or **Target time** and adjust the pace.
4. Set **Text size**. Open **Settings** for alignment, line spacing, mirror,
   guide, countdown, keep-awake, and theme options.
5. Select **Start reading**. The optional countdown holds 3, 2, and 1 for a
   full second each. Tap **Cancel** to stop it.
6. Use **Pause** to stop scrolling, then **Resume** to continue.

Start and stop recording in Moblin. WolfCue does not control recording.
Export a backup before important work. Browser storage can fail or be cleared.

## Move a script into Moblin with a link

1. Paste your script into WolfCue. If it is in Notion, copy the script text
   into WolfCue first.
2. Choose **Export**, then **Copy script link**.
3. Open the copied link in Moblin's private browser.
4. Review the loaded script and confirm replacement if you already have
   different text saved there. Select **Start reading** when ready.

The link contains a text snapshot. It does not connect to or track updates
from a Notion page. Opening it never starts scrolling automatically. For a
script too large to send as a link, use a UTF-8 `.txt` file.
