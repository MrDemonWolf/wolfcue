Do this once on the iPhone that records. It takes about a minute.

<Callout title="One-tap setup">
On the iPhone, open [Set up WolfCue in Moblin](moblin://?%7B%22quickButtons%22:%7B%22buttons%22:%5B%7B%22type%22:%22Browser%22,%22enabled%22:true%7D%5D%7D,%22webBrowser%22:%7B%22home%22:%22https://wolfcue.mrdemonwolf.dev/%22%7D%7D)
in Safari and confirm in Moblin. It turns on the **Browser** button and sets
its home page to WolfCue; then tap **Browser**. If the browser was already open
on another page, type the WolfCue address in it. This link is built from
Moblin's source code and has not been tested on a phone yet. If nothing
happens, use the steps below.
</Callout>

## Step by step

1. **Turn on the Browser button.** In Moblin, open **Settings**, then
   **Display**, then **Quick buttons**, and turn on **Browser**.
2. **Open WolfCue.** Tap the globe **Browser** button and type
   `wolfcue.mrdemonwolf.dev` in the address field.
3. **Save it.** Tap the bookmark button, then **Create bookmark**.
4. **Bring in your script.** Paste it into WolfCue in Moblin's browser, or in
   Safari choose **Copy link for Moblin** and open that link in Moblin's
   browser.

## Read while recording

- Tap **Start reading**, then use the arrows in the browser corner to switch
  to the small view.
- WolfCue keeps the corner with Moblin's expand button clear.
- Use the **Browser** button, not a Browser scene widget. A scene widget shows
  up in your video.

[Use Moblin](/docs/moblin) has the details. Run the
[device checklist](/docs/device-checklist) before a real recording.
