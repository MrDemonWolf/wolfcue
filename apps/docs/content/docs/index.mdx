---
title: WolfCue guides
description: A browser teleprompter for reading while Moblin records.
---

WolfCue has not been verified on a physical iPhone in Moblin. Run the
[device checklist](/docs/device-checklist) before relying on it for a recording.

Paste a script, choose a pace, and read in Moblin's private browser on the same
phone. Your script stays in this browser. WolfCue does not record video or audio.
