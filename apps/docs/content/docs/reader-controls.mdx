---
title: Reader controls
description: Pause, seek, restart, and adjust the reader.
---

Tap the script or select **Pause** to pause. **Resume** continues without
restarting the countdown. The timer counts only active reading time; the
percentage shows scroll progress, not how much you have spoken.

While paused, use **Position** to seek, drag the script with touch or pen, or
use a mouse wheel. Seeking keeps elapsed time. **Restart** resets position and
time and uses the countdown if enabled. **Exit** returns to the editor.

Opening **Settings** pauses the reader. Closing Settings leaves it paused.
Mirror affects only the script, so controls stay readable. Fullscreen appears
only when the browser supports it; it is normally absent on iPhone.

## Keyboard shortcuts

Shortcuts work only in the reader. Typing fields, editable content, composition,
and Ctrl/Meta/Alt combinations are ignored. Space or Enter on a focused button
keeps its normal button action.

| Key | Action |
| --- | --- |
| Space or K | Play or pause |
| Left / Right | Slower / faster: 5 wpm or target +5 / -5 seconds |
| Up / Down | While paused, seek one line back / forward |
| PageUp / PageDown | While paused, seek most of a screen |
| Home / End | While paused, seek start / end |
| R | Restart |
| M | Toggle mirror |
| G | Toggle reading guide |
| - / = | Decrease / increase text size |
| F | Toggle fullscreen if supported |
| Escape | Close Settings, else exit fullscreen, else exit reader |

Changing text size, line spacing, alignment, or viewport size keeps the current
script block and its reading fraction where possible.
